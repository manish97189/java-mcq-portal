# ☕ Java MCQ Portal — Exam Mastery & PYQ Suite

An interactive, high-performance static web application for mastering 120 curated Java MCQs plus official NPTEL Previous Year Questions (PYQs 2024-2025, 2025-2026, and Old MOOC practice questions). Built for university exams, NPTEL certification, technical interviews, and deep conceptual mastery.

## 🚀 Key Features

### 1. 📑 Right-Side PYQ Drawer (Year-Wise Papers)
Switch seamlessly between multiple official NPTEL question banks with one click:
- **📘 PYQ 2024 – 2025 (NOC 25-CS57)**: 120 Questions from the Jan 2024–2025 cycle.
- **📗 PYQ 2025 – 2026 (NOC 26-CS36)**: 120 Questions from the Jan 2025–2026 cycle.
- **📙 Old MOOC Questions for Practice**: 135 foundational NPTEL C & Java MCQs.
- **☕ Core Question Bank**: 120 standard Java MCQs across 12 core curriculum assignments.

> **Zero compromises:** Selecting any paper replicates the entire exam arena, jumbled options mode, topic sprints, flashcard decks, study hub, and learning analytics for that specific paper!

### 2. 💬 Interactive Feedback & Issue Reporting
- Rate overall experience with interactive 5-star ratings.
- Categorize feedback (Question Typo/Bug, Answer Discrepancy, Feature Request, UI/UX, General).
- Quick **"⚠️ Report Question"** button directly available inside active tests and review screens.
- Saves feedback history locally with timestamps.

### 3. 🎯 Full Test & Practice Modes (Replicated for all PYQs)
- **Assignment Sprint**: Select specific topics or assignments.
- **Full Mock Exam**: Timed simulation with countdown or elapsed stopwatch, question palette, and review flags.
- **Anti-Memorization Jumbled Mode**: Shuffles option orders while keeping *"None/All of the above"* pinned to the bottom.
- **Weak Area Drill**: Retest only previously incorrect questions.
- **Saved Questions Deck**: Star tricky questions anytime to create a custom study deck.
- **3D Interactive Flashcards**: Active recall study mode with card flips.
- **Study Hub & Q&A Bank**: Instant live search with a **"Self-Test (Hide Answers)"** toggle.

### 4. 💡 Detailed Explanations & Java Syntax Highlighting
- Detailed step-by-step solutions for every question.
- Formatted Java code snippets with keyword, string, number, and comment highlighting + one-click copy button.
- Option elimination (`✕` strike-through button).

### 5. ⌨️ Keyboard Shortcuts (Press `?` anytime)
- `1` `2` `3` `4` or `A` `B` `C` `D`: Pick option
- `←` / `→`: Navigate questions
- `F`: Flag for review (🚩)
- `S`: Save / Bookmark question (⭐)
- `P`: Open PYQ Papers Drawer (📑)
- `M`: Toggle Sound
- `T`: Toggle Light/Dark Theme
- `Space`: Flip Flashcard
- `?`: Open Shortcuts Modal
